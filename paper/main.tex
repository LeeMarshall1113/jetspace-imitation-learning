\begin{abstract}
\TODO{Write LAST. Five sentences, in this order, numbers already final:
(1)~Frozen visual encoders for robot manipulation are selected by linear-probe
accuracy and evaluated for robustness by held-out error under nuisance shift;
neither practice has been validated against a control. (2)~Across 22 frozen
encoders, 8 nuisance axes and 2 simulated manipulation tasks (1{,}452
encoder--condition arms), five of eight axes fail a discriminability control
--- an untrained CNN is not in the worst third, identically on both tasks ---
and absolute held-out error is an exact monotone transform of probe accuracy
($\rrho = -1.000$ on all 16 cells), so the standard metric partly re-measures
the probe it is meant to validate. (3)~On the axes that survive, a top group
(V-JEPA~2, AIMv2, DINOv3) significantly outperforms VC-1, the purpose-built
robotics encoder (paired bootstrap, all CIs excluding zero), and VC-1 also
ranks below a plain ImageNet ViT under the same protocol on CortexBench's own
demonstrations. (4)~The same control run on CortexBench \emph{passes},
locating the failure specifically in axes built by corrupting a reference
condition. (5)~Experiments were pre-registered; all deviations, failed
predictions and retracted interim findings are reported.}

\subsection{The identity, and the primary metric}
\label{sec:identity}
With every encoder scored against the same held-out actions,
$\mathrm{probe}\ R^2 = 1 - \mathrm{ss}_{\mathrm{res}}/\mathrm{ss}_{\mathrm{tot}}$
and $\mathrm{ref\ MSE} = \mathrm{ss}_{\mathrm{res}}/N$ share
$\mathrm{ss}_{\mathrm{tot}}$ and $N$ across encoders, so one is an exact
decreasing function of the other: measured $\rrho = -1.000$ on all 16
axis--task cells. \TODO{Two more sentences: absolute held-out error therefore
partly re-measures baseline fit; \reldeg{} removes the shared factor.
Table~\ref{tab:signflip} shows the consequence.}
