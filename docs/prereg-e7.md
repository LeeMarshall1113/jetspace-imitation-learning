# Pre-registration — E7: does video pretraining buy *policy* viewpoint generalization?

Written and committed before the experiment ran. Prior looks disclosed in §4.

## 0. Why this experiment exists

E6 compared a frozen V-JEPA 2 encoder against a frozen random CNN and concluded:

> A frozen 326M video foundation model buys nothing consistent over random
> convolutional features at this data scale.

That conclusion is about **world-model quality** — direction cosine, rollout
ratio, inverse-dynamics probe R². All three are internal to the predictor.

It says nothing about the question this project was started to answer: whether a
pretrained video encoder lets a policy trained on **one viewpoint** keep working
at viewpoints it never saw. Pretraining could easily fail to improve one-step
latent prediction while still producing features that are more stable under
camera movement — those are different properties, and no experiment here has
separated them. The wider literature has not either.

If pretraining buys viewpoint generalization, that is a positive result for the
premise this project was founded on. If it does not, E6's negative extends from
world models to policies and the premise is refuted twice, which is worth
knowing before more is built on it.

## 1. Design

Identical to E6's controls, applied to a policy head instead of a predictor.

| arm | encoder | params | frozen |
|---|---|---|---|
| `vjepa` | V-JEPA 2 ViT-L, pretrained | 326M | yes |
| `rand` | scratch CNN, never trained | 7.5M | yes |

Both emit `(T', 4, 4, 1024)` at `frames_per_latent=2`. Same head (linear →
ReLU → linear → 6 actions), same optimiser, same epochs, same three seeds, same
episodes, same 23 R1 camera poses. The **only** difference between arms is which
frozen encoder produced the features.

Train the head on `r1_ref` only. Evaluate action-prediction error at all 23
poses. The head never sees a displaced viewpoint.

**Measure.** Normalised action MSE at each pose, and **retention** = (error at
reference) / (error at pose), so 1.0 means the viewpoint cost nothing.

## 2. Registered predictions

**E7a — the primary claim.** V-JEPA retains more than random CNN, averaged over
the 22 displaced poses. **Registered: mean retention gap ≥ 0.05 in V-JEPA's
favour, with non-overlapping 95% intervals across three seeds.**

**E7b — the effect grows with displacement.** If pretraining buys viewpoint
robustness, the advantage should be larger at large camera displacements than
small ones. **Registered: V-JEPA's retention advantage at the six largest-gap
poses exceeds its advantage at the six smallest by ≥ 0.03.** A flat advantage
would indicate a constant offset in fit quality rather than robustness.

**E7c — falsifier.** If random CNN retains as well or better
(gap ≤ 0 within intervals), E6's negative result extends to policies, and this
project should stop treating the pretrained encoder as load-bearing. **This
outcome is reported as the headline if it occurs**, not buried.

## 3. Invalidation conditions

Registered in advance; any one of these voids the run rather than producing a
verdict.

1. **Reference fit floor.** If either arm cannot fit the reference pose itself
   — normalised MSE ≥ 0.9, i.e. barely better than predicting the mean action —
   there is no dynamic range and no verdict is issued. This is the R2 defect:
   that script reported a confident failure off a policy that succeeded 3.3% of
   the time, and the floor precondition now in `run_r2_task_success.sh` exists
   because of it.
2. **Feature-count mismatch.** If the two arms yield different numbers of
   latents per episode, the alignment between latents and actions differs
   between arms and the comparison is not matched. Checked and asserted.
3. **Encoder configuration drift.** `pool_grid` and `hidden` must be identical
   across arms. Ledger L7 is what happens otherwise: two runs differing only in
   `pca_dim` produced an apparent finding that was an artefact.

## 4. Prior looks — full disclosure

- **E6 has already run** on these encoders, on three tasks, and found no
  consistent advantage on world-model metrics. That is the reason for this
  experiment and the reason E7c is a live possibility rather than a formality.
- The V-JEPA latents for all 23 reach poses are **already cached** from R1/H1.
  No V-JEPA feature has been looked at through a policy head.
- The random-CNN features for these poses **do not exist yet** and will be
  generated by this experiment.
- Reach policies at 90.7% success exist, but they use the small end-to-end CNN
  with a spatial-softmax head, which is neither arm here. No policy-level
  encoder comparison has been run at any point in this project.

## 5. What follows either way

If E7a holds, the online version is worth GPU time: task success across poses
for both arms, which is the behavioural claim. If E7c fires, no online run is
justified and the paper's framing does not rest on pretraining.
